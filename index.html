3 Observações e anexo

✓ Cotação adicionada ao painel
Ao adicionar, a cotação é salva direto no banco de dados na nuvem (Firebase) e o painel atualiza na hora — em qualquer dispositivo aberto neste link. Para levar os dados para fora do app, use Exportar Excel ou Exportar PDF na tela de Cotações.

📑 Adicionar várias cotações de uma vez (Excel)

Baixe o modelo, preencha no seu computador e importe de volta — todas as linhas viram cotações no painel em um único envio.
✓ Cotações importadas
O modelo já vem com as colunas certas e uma aba de instruções com os valores aceitos para Vendedor, Operação, Modal e Status. Depois de preencher, clique em "Importar planilha preenchida" para enviar todas as linhas direto para a nuvem — sem precisar cadastrar uma por uma.
